边界

这份证据没有承诺什么

  • 合成代理仍缺产品候选的 M7 live/bin 分解、产品业务时延，以及真实并发分配线程的直接全-arena 锁停顿。
  • gst trim 在 PLAYING→NULL release 后触发；它测到下一循环业务墙钟，但没有把 trim 放进并发分配热区。
  • “p99 未检出”不等于“零代价”：结论严格受三重复、50 个主样本与预登记离散门约束。判定证据
  • 同 seed 不钉 arena 指派：单重复实测出现 68.169197%（约 1 MiB 页台阶）；回收字节值不属于确定性项，S4 B 分别锚定发布值 81.661264% / 84.446566% 并按每档三重复中位 ±5 pp 验收。n=3 的中位至多容忍一个离群。机器规则
  • known-alert waiver 不是无害性证明：S4 A 最多 2 个匹配 alloc_bench cpu.relative 的 livedump；触发理由与窗口可复现，但未做根因证明。观测到且完成记录、归档、精确清理和复核才记 EXPECTED，未观测只记 REGISTERED/NOT-EVALUATED；其他可归因告警仍失败。健康门模板
