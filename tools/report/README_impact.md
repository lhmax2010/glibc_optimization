# 独立影响报告的构建与交付边界

报告作为单个 HTML 文件直接交付；读者不需要仓库或任何配套文件。图表和样式
全部内联，只保留可用的页内导航，不包含证据链接、文件路径或复算命令。
末尾仅保留 PM 指定的仓库名与标签说明，不生成超链接。以下构建命令和证据
校验说明仅面向维护者，不写入对客 HTML，也不改冻结交付包。

## 维护者重建（main）

```sh
python3 tools/report/build_impact_report.py
python3 tools/report/build_impact_report.py --check
python3 tools/report/build_impact_report.py --lang en
python3 tools/report/build_impact_report.py --lang en --check
python3 -m unittest tools.report.test_build_impact_report
```

生成器和本报告专属测试位于 main，不在 demo-v14 中。读者只需打开收到的
HTML，不必克隆、验包或重建。main 的完整
`reproduce.sh verify` 通过既有报告测试模块发现这些测试；入口字节不变。

## 三个构建硬门

- 数字：`impact_sources.json` 固定公开输入字节哈希；按行重算已有统计并
  对照已发布精确值，不改任何测量数据或统计定义。`impact_delivery.json`
  固定 demo-v14 的完整提交 SHA，继续严格核验输入与该快照的证据字节一致。
  这是维护者构建时的来源校验，不是读者的阅读前提。缺少对象时明确失败并提示
  `git fetch --no-tags origin 7289a47b9d24791944cd3b02c00f24b8cb76aa3b`，不降级跳过。
- 单文件：所有 href 只允许指向实际存在的 `#锚点`；即使某文件已公开且
  存在于交付快照，指向它的链接也必须失败。正文路径、外部资源、脚本或
  自动跳转同样拒绝；测试把 HTML 单独放进空目录，证明不依赖配套文件。
- 用词：检查生成的完整 HTML（含图注、属性、meta、注释）及拼接后的文本；
  禁止相关署名、过程用语以及本轮要求去掉的统计术语。实体、大小写、全角
  与零宽字符均纳入检查。回归测试覆盖正文以外的命中，以及 CLI 返回非零、
  不写入新文件且不覆盖已有文件。

## 2026-09-16 单文件交付修订

按 PM 要求移除所有文件链接、路径和读者复算步骤，仅保留页内导航；不再
假设总部持有仓库。统计术语改为通常耗时、最长操作、代表值和重复测量波动
的中文解释。取值位置、首次/全周期时段、系统侧无法确认真实变化、通常
耗时的小幅变慢、冷启动例外等原有限定保留，未改计算或已发布数据。
“代表值”是排序后居中取值；业务通常耗时仍保留 nearest-rank 的既有取值
位置，并在正文用“居中的两轮里较快的一轮”解释，不偷换为另一个算法。

## 2026-09-16 平行英文版

默认语言仍为 `zh-CN`；`--lang en` 生成独立英文 HTML。两版均可单文件分发，
语言切换只用纯文字提示，英文版注明以中文技术文档为准。
`impact_en.json` 只翻译文本与可读标签，共用中文页面的结构、图形坐标和数字。
数值占位符必须逐个、原序、原字符串保留；缺翻译、改数字或禁用词均构建失败。

跨语言测试逐文本节点比较数字（含符号与百分号）、全部章节/导航/图形属性，
并逐项比对 11 条限定语的出现次数。原单文件、禁用词、冻结证据与数字硬门
对两版共同生效；这些测试随既有报告模块进入完整 verify，入口字节不变。
